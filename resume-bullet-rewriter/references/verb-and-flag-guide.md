# Verb and flag guide (SkillHearth)

Original guide for this skill. Pick the verb that matches what the user actually did. If you cannot tell which row applies, ask the one question instead of choosing the stronger row.

## Flag definitions
| Flag | Test | Typical fix |
|---|---|---|
| VAGUE | Could the same sentence appear on any resume? | Add object/scope/context the user stated, or `[ADD: ...]` |
| WEAK VERB | Opens with "responsible for", "helped", "worked on", "assisted", "involved in", "handled", "participated", "duties included" | Replace with a verb at the same level of involvement |
| NO RESULT | States activity only | Ask what changed or was produced; do not guess |
| REPEATED | Same first verb 3+ times, or same duty in 2+ bullets | Vary verbs honestly or merge the bullets |
| UNVERIFIABLE CLAIM | Number/superlative without support in the conversation | Keep only if the user confirms it is real; else `[ADD: ...]` |

## Verb options by level of involvement
| User said / did | Safe verbs | Do NOT use unless stated |
|---|---|---|
| Did the task personally | Prepared, Processed, Wrote, Built, Updated, Reviewed, Scheduled, Tracked, Answered, Filed, Tested | – |
| Helped someone else do it | Supported, Contributed to, Assisted, Collaborated on | Led, Owned, Drove, Spearheaded |
| Worked with a group | Coordinated with, Collaborated with, Worked with | Managed, Directed |
| Was in charge of a process or area | Ran, Maintained, Administered, Oversaw (only if "in charge" is stated) | Founded, Transformed |
| Led people | Led, Supervised, Trained, Mentored (only if the user said they led/trained people, and how many if known) | Invented team sizes |
| Started something new | Launched, Set up, Created (only if the user said it did not exist before) | Pioneered, Revolutionized |
| Made something better | Reduced, Increased, Shortened, Improved (only with a stated before/after or direction) | Any percentage or amount not given |

## Placeholder patterns
- `[ADD: number of <things> per <period>]`
- `[ADD: result – what changed or was delivered]`
- `[ADD: tool or method you used]`
- `[ADD: size of team/client base/budget you worked with]`
- `[ADD: time period or frequency]`

Keep one placeholder type per sentence when possible, so the single question stays answerable in one line.
